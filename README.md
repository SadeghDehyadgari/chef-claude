# 🧠 AI Recipe Assistant  

A React project from **Scrimba** focused on practicing key React concepts like **state**, **components**, **props**, and **API integration**.  
This app connects to the **OpenRouter AI API** to generate **custom recipe ideas** based on ingredients you provide.  

## ✨ Features  
- ⚛️ Built with React + Vite  
- 🧩 Demonstrates use of state, components, and props  
- 🤖 Fetches AI-generated responses from OpenRouter API  
- 🥗 Ask the AI to create recipes from any ingredients you have  
- 📝 Uses React Markdown for clean and readable output  

## 📁 Project Setup  
1. Clone the repository:  
   ```bash
   git clone https://github.com/yourusername/ai-recipe-assistant.git
   ```
2. Navigate into the folder:
   ```bash
   cd ai-recipe-assistant
   ```
3. Install dependencies:
   ```bash
   npm install
    ```
4. Create a .env file in the root directory and add your OpenRouter API key:
   ```bash
   VITE_OPENROUTER_API_KEY=your_api_key_here
    ```
5. Start the development server:
   ```bash
   npm run dev
    ```
